# English Practice (A1 → A2)

專為中文使用者設計的簡單英文 Flashcard + 練習題網頁。

## 功能
- Flashcard 翻卡複習（點擊卡片翻面）
- 練習題（選擇 + 填空）
- 手機友善介面

## 使用方式
直接打開 `index.html` 或啟用 GitHub Pages。

## GitHub Pages
1. 到 repo Settings → Pages
2. Source 選 `Deploy from a branch`
3. Branch 選 `main` / `/ (root)`
4. 儲存後等待一兩分鐘即可線上使用

線上網址範例：
`https://siumeifc1988-sketch.github.io/english-practice/`

## 之後可擴充
- 加入更多卡片與題目
- 連接每日自動更新內容
- 加入進度記錄 (localStorage)
